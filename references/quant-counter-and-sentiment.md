# 量化时代反收割战法与情绪周期定量打分模型

2025-2026 年 A 股短线生态中, 高频量化资金深度介入涨停打板与首板平铺, 传统"无脑打首板/追中位跟风"极易被次日高开秒砸收割。本手册提供针对量化生态的反制铁律与情绪周期定量温度计。

## 1. 量化资金四大收割套路与反制铁律

| 量化收割套路 | 盘面典型特征 | 龙头战法反制策略 |
| :--- | :--- | :--- |
| **1. 题材首板量化平铺** | 突发消息后 3 分钟内同题材十几只小盘股脉冲拉板, 龙虎榜全是量化席位对倒 | **绝不追首板与后排平铺股**; 次日 80% 会无脑低开核按钮, 耐心等二进三/三进四换手淘汰出唯一真龙再看 |
| **2. 次日高开秒砸(量化兑现)** | 昨日封单成交比 `< 0.5` 或尾盘偷袭板, 次日 `09:25` 缩量虚高开 `+2%~+4%`, `09:30` 开盘 1 分钟直砸水下 | 严格执行 `dragon_calc.py auction` 爆量检验: 竞价成交额不足昨日 `3%` 的虚高开一律不追, 开盘破均价线立即观察兑现 |
| **3. 盘中脉冲诱多(钓鱼线)** | 低开水下后突然直线脉冲拉升 `+7%` 以上却不封死, 诱使追涨盘进场后反手砸绿 | 严守硬规则: **低开急拉超 `+7%` 不封板绝不半山腰追高**, 只看换手回封确认或回踩 5 日线缩量企稳 |
| **4. 反复炸板收割与假翘板** | 全天开板 4 次以上、封单不断撤单诱多, 或跌停板脉冲翘板 3 分钟再封死跌停 | **严禁接反复烂板、严禁盲目跌停翘板**; 优先选择有**机构+北向+顶级游资共振**的大容量高辨识度真龙, 量化资金无法轻易控盘砸死 |

## 2. 情绪周期五维定量打分体系 (0-100 情绪温度计)

每次早晚盘复盘前, 使用 `scripts/dragon_calc.py sentiment` 输入当日五大硬指标计算客观温度分, 彻底杜绝凭感觉误判周期:

- **涨停家数(`--lu`)**: `< 35` 偏冷, `45-90` 正常活跃, `> 120` 警惕一致性高潮。
- **跌停家数(`--ld`)**: `<= 5` 安全, `10-25` 分歧加大, `>= 30` 退潮/冰点警报。
- **炸板率(`--bomb`)**: `< 25%` 强一致, `25%-40%` 良性分歧, `>= 45%` 强分歧/兑现潮。
- **连板晋级率(`--promo`)**: `< 20%` 接力冰点, `30%-60%` 健康接力, `>= 80%` 一致高潮次日防剧烈分化。
- **最高连板高度(`--max-board`)**: `<= 3` 高度压制, `4-6` 正常赚钱窗口, `>= 7` 逼近监管/卡异动周期末段。

### 温度分区间与仓位映射

| 温度分 / 触发条件 | 周期定性 | 仓位上限 | 核心作战指引 |
| :--- | :--- | :--- | :--- |
| **`< 25` 或 跌停 >= 30** | **退潮 / 极度冰点期** | `0% - 20%` | 空仓防守为主, 仅盯最先抗跌逆势的 1 只穿越活口, 严禁接力中位股 |
| **`25 - 45`** | **弱势分歧 / 筑底试错期** | `20% - 30%` | 轻仓只做唯一真龙首阴 5 日线低吸或冰点后首只弱转强 |
| **`45 - 70` (且炸板率 < 45%)** | **主升 / 良性换手期** | `50% - 70%` | 最佳赚钱窗口, 聚焦表A唯一真龙与最高身位换手龙 |
| **`70 - 85` (但炸板率 >= 45%)** | **高潮次日强分歧期** | `30% - 50%` | 去弱留强, 严禁追高开后排, 只做绝对总龙分歧承接或最高位断板弱转强 |
| **`> 85` 或 涨停 >= 130 且晋级率 >= 80%** | **情绪一致高潮预警期** | `40% - 60%` (只卖不追一致) | 严防次日早盘一致高开后高开低走兑现, 持仓逢一致加速择机锁利 |
