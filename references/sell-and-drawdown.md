# 龙头精准逃顶卖点、动态回撤控仓与周期复盘清单

"高手买入龙头, 超级高手卖出龙头。" 买点决定你能不能上车, 卖点与回撤控制决定你能不能把利润带走、实现稳定复利。

## 1. 龙头六大硬核逃顶卖点(盘中/尾盘机械执行)

没有完美逃顶, 只有提前写好的机械预案。触发以下任一信号, 立即按预案减仓或清仓, 绝不幻想:

1. **高位放量炸板且全天无力回封**: 最直观的见顶信号。高位首次炸板后回撤破分时均价线、反复回封失败且换手飙升, 直接兑现离场。
2. **一致加速次日高开低走(卖在一致)**: 连续缩量加速/一字板叠加东财+同花顺+淘股吧三平台一边倒狂吹后, 次日早盘大幅高开却无法快速封板、放量跌破分时均价线(黄线), 借情绪一致高潮直接落袋。
3. **高位巨量滞涨(换手过热)**: 连续两天换手超 `50%` 却收长上影、十字星或小阴线(尤其逼近 10 日 `+100%` 严重异动红线下方 2%-3%), 筹码从锁筹转为派发, 果断撤离。
4. **板块后排集体大跌背离**: 龙头仍在高位硬撑, 但同板块中军与后排梯队已经大面积跳水、跌停增多, 说明板块合力瓦解, 龙头大概率滞后补跌。
5. **收盘有效跌破 5 日均线**: 连续涨停或趋势主升的龙头, 尾盘 `[14:30-14:55]` 确认无法收回 5 日均线上方, 宣告主升惯性终结, 严格执行离场。
6. **尾盘偷袭板次日无溢价**: `14:40` 以后偷袭封板且封单成交比 `< 0.5`, 次日早盘冲高滞涨或直接平开走弱时第一时间获利了结。

## 2. 买入假设审计法(闭上嘴巴, 睁开眼睛, 动手操作)

不要试图当上帝预测大盘涨跌, 而是把每一笔交易拆成可验证的逻辑闭环:

1. **建仓前写死假设**: 明确写出买它的唯一理由(例如: A级主线唯一换手卡位龙 / 竞价爆量弱转强)。
2. **盘中持续对照**: 若盘面反馈符合预期(板块助攻、分时稳在均线上方), 耐心拿到卖点; 若盘面证伪了买入理由(板块掉队、核按钮破位、无承接阴跌), 毫不拖延按纪律认错。
3. **克服成本障碍**: 买入或卖出只取决于当下赔率与逻辑是否成立, 与你的持仓成本无关; 绝不因为亏了几个点就补仓摊平成本。

## 3. 游资动态回撤控制与阶梯仓位机制

短线高手与普通选手拉开差距的核心不是抓了多少涨停, 而是**控制回撤的能力**, 防止情绪预算失控导致报复性重仓:

| 账户回撤 / 状态 | 强制仓位上限 | 铁血执行动作 |
| :--- | :--- | :--- |
| **正常盈利/顺风期** | 按情绪周期(强势 60%-80%, 震荡 30%-50%) | 严禁连赢后膨胀松动止损线或随意加杠杆 |
| **单笔大面止损当日** | **0%(强制冷却)** | 当日彻底停止开新仓, 杜绝情绪上头报复性翻本 |
| **连续 2-3 笔亏损 / 回撤达 5%-8%** | **仓位减半(≤ 20%-30%)** | 强制切换至小仓试错模式, 必须等连续赚回 1-2 笔确认手感与周期共振后再恢复仓位 |
| **单月回撤触及 10% 红线** | **0%-10%(空仓反思)** | 强制空仓休息 2 个交易日, 逐笔审计交割单找系统漏洞, 严禁逆势死磕 |

## 4. 空间龙 vs 周期龙(穿越龙)与每日五件必做复盘

- **空间龙(连板高度标)**: 负责打开连板高度天花板, 往往一字缩量或筹码过热, 断板极易核按钮, 多数时候放表B作温度计。
- **周期龙 / 穿越龙(真正的大肉载体)**: 在大盘退潮冰点或板块分歧日先于大盘止跌、逆势抗跌甚至反包涨停, 穿越旧周期退潮并引领新周期主升(经过充分换手检验), 是表A唯一值得重仓格局的核心。

### 每日盘后五件必做复盘清单(固化周期感)
1. **过一遍涨停与炸板池**: 记录所属板块与封板时间, 看清资金共识往哪流。
2. **标记最高连板高度与晋级率**: 锚定当前情绪周期所处精确阶段(冰点/启动/高潮/退潮)。
3. **核对龙头与跟风强弱关系**: 看板块内是否出现高低切换或卡位分离。
4. **写下明日表A/表B应对预案**: 标死竞价弱转强阈值、`-5%` 熔断价与 5 日线止损位。
5. **逐笔审计当日交易**: 核验每一笔操作的买入理由是否依然成立, 记录卖飞或失误案例。
