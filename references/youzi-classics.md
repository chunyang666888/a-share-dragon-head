# A股短线游资典籍与情绪周期心法库

本文档整合《炒股养家心法》、赵老哥、退学炒股、陈小群、北京炒家、职业炒手、Asking、瑞鹤仙、乔帮主、章盟主等 23 位著名游资典籍与 GitHub 开源游资 Skill(`AIPMAndy/youzi-trading-skill`、`sherjy/wudao-hero-skill`)的核心精华。

## 1. 情绪周期与群体博弈(炒股养家 / 涅槃重生 / 陈小群)

超短交易的本质是群体博弈, 核心在于衡量场外潜在买盘与场内获利筹码的倾向变化, 而不是预测个股基本面。

### 情绪周期四阶段与操作映射

1. **冰点/酝酿期**: 跌停家数见顶回落, 亏钱效应极致宣泄, 场内筹码从"不计成本割肉"转向"下跌空间有限"。此时以空仓观望为主, 紧盯最先抗跌、逆势穿越的新周期试错活口。
2. **启动/发酵期**: 市场情绪逆转, 赚钱效应显现, 出现 3 连板以上新题材先锋并带动板块跟风。策略: 买入在分歧转一致的确认节点, 敢于聚焦主线前排。
3. **高潮/加速期**: 龙头连续缩量加速或一字板, 板块大面积涨停, 全网大V一致看多。策略: 卖在一致(陈小群核心心法), 严禁此时接力后排跟风杂毛, 持仓者借一致高潮逐步兑现或收紧止盈线。
4. **退潮/核按钮期**: 最高空间板炸板大面、天地板或一字跌停, 昨日涨停溢价转负。策略: 无条件防守, 大幅降仓或直接空仓休息, 等待下一轮冰点出清。

### 陈小群: 分歧 -> 一致 -> 加速 -> 分歧循环

- 买点在**分歧**(恐慌洗盘但核心龙头承接未死、跌不动且有资金抢筹)。
- 卖点在**一致**(所有人都看懂、全网一致狂吹、缩量加速买不到后的次日兑现)。
- 龙头倒了, 板块内一切后排跟风都是假的, 绝不做杂毛反抽。

## 2. 八大游资流派实战精华速查

| 流派与代表人物 | 核心心法 | 选股锚点 | 买卖与风控铁律 |
| :--- | :--- | :--- | :--- |
| **情绪周期派**(炒股养家、涅槃重生) | 揣摩赚钱效应与赔率, 买入机会、卖出风险 | 主流题材总龙, 不做支流与边缘题材 | 弱市空仓, 强市重仓; 买入不看成本, 只看当下赔率 |
| **龙头主升派**(赵老哥、著名刺客) | 高手买入龙头, 超级高手卖出龙头 | 新题材 3 连板启动、先于大盘止跌、带板块效应 | 亏损单不过夜; 只做主升与惯性, 筑顶果断撤离 |
| **弱转强纠错派**(退学炒股) | 克服成本障碍, 市场永远是对的 | 高辨识度换手核心, 分歧次日超预期弱转强 | 卖飞不可怕, 走出超预期敢于纠错买回; 买错绝不幻想 |
| **纪律顺势派**(职业炒手、Asking) | 耐心 + 顺势而为 + 知行合一 | 高流动性上升趋势与主线焦点 | 弱市不做, 走弱即出, 拒绝频繁手痒交易 |
| **打板确认派**(小鳄鱼、令狐冲) | 打板买的是确定性与次日溢价 | 换手板、情绪转折板、当日市场焦点 | 板上确认, 炸板无承接快速认错处理 |
| **熊市保命派**(瑞鹤仙、不动明王) | 熊市先保命, 活下来才有复利 | 只做最强核心或大势共振的大容量票 | 熊市轻仓空仓, 不抄半山腰阴跌股 |
| **低吸回踩派**(乔帮主) | 龙头多一条命, 急跌回踩买性价比 | 强势龙头首阴或回踩 5日/10日均线 | 缩量企稳低吸, 支撑有效跌破立刻止损 |
| **稳健控回撤派**(北京炒家) | 慢就是快, 机械执行, 板块效应第一 | 必须有板块梯队共振, 拒绝独苗 | 严控单笔回撤, 绝不因情绪上头加码摊平 |

## 3. 交易心理学与反面教材警戒(大曾子反面清单)

以下五种典型散户死法必须在诊断用户持仓或盘中咨询时直接亮红牌警告:

1. **盲目补仓摊成本**: 跌了加仓拉低均价是短线大忌, 有补仓念头说明心里仍被成本锚定, 忘记了"对错比盈亏重要"。
2. **退潮期手痒抄底**: 游资没有靠抄底阴跌股把小资金做大的; 跌停翘板九死一生, 严禁接飞刀。
3. **买不到龙头去买后排杂毛**: 龙头涨停买不到就退而求其次买跟风, 结果龙头一分歧跟风直接核按钮。
4. **连赢之后加杠杆/松止损**: 账户新高时最容易把周期红利误当成自身神技, 一笔大回撤吞掉整月利润。
5. **听群聊/大V一致狂吹去追高**: 舆论最一致时往往是先手资金派发筹码的终点。
