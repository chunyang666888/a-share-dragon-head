# 进阶盘口、集合竞价真伪识别与身位卡位战法

本文档聚焦龙头战法中真正拉开胜率的微观盘口细节与周期切换艺术, 包括集合竞价防骗炮、封单成交比定量评估、分时承接识别及同身位卡位分离模型。

## 1. 集合竞价 10 分钟微操暗门 (09:15 - 09:25)

集合竞价遵循**最大成交量优先**原则(其次最小未成交量、最后参考前收盘价就近), 是全天多空博弈的第一个锚。

- **`09:15 - 09:20` 假单诱多陷阱(只看不动)**: 允许自由撤单。部分资金会用巨额买单把虚拟开盘价推高到涨停或 `+6%` 以上制造抢筹假象, 然后在 **`09:19:50 - 09:19:59`** 集中撤单砸出真实低开。此阶段**只看方向, 不信数量**。
- **`09:20 - 09:25` 真实承诺窗口(核心定调)**: 撤单权限关闭, 每一笔挂单都是真金白银的承诺。真正有效的竞价弱转强必须满足:
  1. `09:20` 后虚拟开盘价稳步上移或稳住高开 `+2%` 至 `+5%`, 未出现大幅回落;
  2. **竞价爆量达标**: 昨日分歧/烂板/断板标的, 今日 `09:25` 竞价成交额需达到昨日全天成交额的 **`3%–8%`** 以上(换手充分且真金白银抢筹), 否则缩量虚高开极易开盘秒砸。
- **`09:25 - 09:30` 挂单真空期**: 撮合已完成但连续竞价未开, 尽量不在此时挂需要随时撤改的单子。

## 2. 涨停封板成色与封单成交比定量模型

打板或持仓看次日溢价, 核心看**封板质量**与**封单成交比**(收盘买一封单量 / 当日总成交量):

| 指标维度 | 强封与高溢价信号 | 弱封与派发警报 |
| :--- | :--- | :--- |
| **封单/成交比** | `> 1.0` (特别是 `3.0` 以上), 次日高开大概率 `+3%~+6%+` | `< 0.5`, 封板根基极弱, 次日平开甚至低开概率极高 |
| **流通盘封单绝对量** | 流通盘 1-3 亿股封单需 4-5 万手以上, 3-6 亿股需 8 万手以上 | 封单稀疏且买一挂单在接近涨停时频繁撤单(虚假托单诱多) |
| **烂板回封质量** | 炸板后分时回撤不破均价线(或跌幅 `< 5%`), 低点逐波抬高, 一波放量干脆回封 | 炸板后深水杀跌无力、全天反复开板 4 次以上、回封越来越弱且爆天量滞涨 |
| **封板时间窗口** | 早盘 `09:30-10:15` 换手回封最有主动性 | `14:40` 以后才偷袭封板且板块无助攻, 次日极易低开核按钮 |

## 3. 分时盘口“真承接”与“假反弹”一眼辨别

- **真承接分时特征**: 急跌时呈**尖底 V 型**, 跌到关键均线或昨日收盘价附近立刻有大单主动扫货托底, 分时白线(现价)始终压着或紧贴黄线(均价线)运行, 不出现长时间阴跌破位。
- **假承接/出货分时特征**: 每次脉冲拉升量能放大但马上被砸回(尖顶倒 V), 随后无量阶梯式阴跌, 黄线一路向下压制白线——任何反抽不过黄线都是卖点而非买点。

## 4. 身位卡位、分离确认与周期高低切换

### 同身位 PK 淘汰法则
当同一天出现两只同高度高标(例如同为 3 连板或 4 连板):
1. **看主动性与换手**: 谁在分歧日率先带量抗跌上板、谁带动了更多同板块小弟涨停, 谁就是真卡位龙; 靠缩量一字霸占高度却澄清无关联的(如克来机电式), 一旦开板即被抛弃。
2. **分离确认点**: 当另一只同身位竞争者率先炸板掉队甚至跌停时, 逆势抗住分歧封死涨停的那一只即完成**分离确认**, 成为全市场唯一的身位总龙。

### 周期“高低切换”信号
- 当最高位空间总龙已经历 2 天 `50%+` 极度天量换手、触及严重异动红线或被发监管工作函, 同时早盘低位 1 进 2 / 2 进 3 出现**新题材批量涨停(3 只以上)** 且大盘放量时, 资金往往从高位老龙向新周期低位 2-3 板换手前排切换——此时严禁在高位老龙里硬抗补跌, 果断切往新周期唯一先锋。
